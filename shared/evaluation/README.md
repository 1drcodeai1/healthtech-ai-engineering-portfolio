# Evaluation

Reusable evaluation tools for HealthTech AI systems.

## Planned Components

- Retrieval metrics
- Precision@K and Recall@K
- Mean Reciprocal Rank (MRR)
- Citation accuracy checks
- Faithfulness evaluation
- Performance reports

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib

## Purpose

Measure the quality, reliability, and performance of AI workflows.
