# Shared Components

Reusable components and utilities for all projects in this HealthTech AI Engineering Portfolio.

## Directory Structure

- synthetic_data/: Synthetic clinical data generation
- schemas/: Data models and schemas
- validators/: Data validation utilities
- evaluation/: Evaluation metrics and tools
- retrieval/: Document retrieval components
- logging/: Logging and traceability utilities
- ui/: Reusable interactive interfaces

## Purpose

To promote modularity, consistency, code reuse, and maintainability across all projects.

## Privacy

All clinical examples and generated patient records are synthetic. No real patient information is used.
