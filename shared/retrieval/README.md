# Retrieval

Reusable document retrieval components for evidence-based AI systems.

## Planned Components

- Document loaders
- Text chunking utilities
- Embedding generation
- Semantic search
- Keyword search (BM25)
- Hybrid retrieval
- Reranking utilities

## Technologies

- Python
- Sentence Transformers
- FAISS
- BM25

## Purpose

Provide reusable and explainable document retrieval components for RAG applications.
