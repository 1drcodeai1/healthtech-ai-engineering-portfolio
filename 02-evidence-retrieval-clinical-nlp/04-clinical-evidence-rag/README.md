# 04 - Clinical Evidence RAG

## Overview

A Retrieval-Augmented Generation (RAG) system that retrieves relevant scientific evidence to answer questions using trusted clinical sources.

## Technologies

- Python
- LangChain
- Sentence Transformers
- FAISS
- BM25
- Google Colab

## Main Features

- Scientific document ingestion
- Text chunking and embeddings
- Semantic and keyword retrieval
- Evidence-grounded answers
- Verifiable source citations
- Abstention when evidence is insufficient

## Evaluation

The system will be evaluated using retrieval metrics and answer quality checks.

## Data Privacy

This project uses public scientific documents and synthetic questions. It does not provide medical diagnoses or replace professional clinical judgment.
