# 05 - Clinical Entity Extractor

## Overview

An NLP-based assistant that identifies and structures clinical entities from synthetic medical notes.

## Technologies

- Python
- spaCy
- Transformers
- Pydantic
- Google Colab

## Main Features

- Clinical named entity recognition
- Identification of symptoms, medications, and procedures
- Entity normalization
- Candidate terminology mapping
- Structured JSON output

## Safety and Limitations

Extracted entities and terminology suggestions require human review. This project does not establish diagnoses or perform definitive medical coding.

## Data Privacy

This project uses synthetic clinical notes only.
