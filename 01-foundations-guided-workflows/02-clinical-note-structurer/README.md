# 02 - Clinical Note Structurer

## Overview

An NLP-based tool that transforms synthetic clinical notes into structured data.

## Technologies

- Python
- spaCy
- Regular Expressions
- Pydantic
- Google Colab

## Main Features

- Clinical entity extraction
- Identification of symptoms and medications
- Structured JSON output
- Detection of negated and undocumented information

## Data Privacy

This project uses synthetic clinical notes only. It does not process real patient records.
