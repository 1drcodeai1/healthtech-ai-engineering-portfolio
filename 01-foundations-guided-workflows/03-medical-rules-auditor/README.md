# 03 - Medical Rules Auditor

## Overview

A rule-based system for validating synthetic clinical records and identifying inconsistencies.

## Technologies

- Python
- Pandas
- Pydantic
- Pandera
- Pytest
- Google Colab

## Main Features

- Clinical data validation
- Missing field detection
- Date and unit consistency checks
- Rule-based auditing
- Explainable validation reports

## Data Privacy

This project uses synthetic clinical data only. It does not make diagnoses or replace professional clinical judgment.
