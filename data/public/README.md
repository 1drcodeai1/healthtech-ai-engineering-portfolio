# Public Data

This directory stores or references publicly available datasets and scientific documents used in the portfolio.

## Planned Sources

- PubMed Central Open Access
- Synthea public resources
- Public clinical terminology resources
- Other openly licensed research datasets

## Requirements

- Verify the license before using any resource.
- Document the original source.
- Respect attribution and redistribution requirements.
- Avoid restricted or identifiable patient information.

## Privacy

Only resources suitable for public research and demonstration will be included.
