# Data Sources and Licensing

This document tracks the datasets and scientific resources used across the HealthTech AI Engineering Portfolio.

## Data Sources

| Source | Intended Use | License / Access | Status |
|---|---|---|---|
| Synthetic generated data | Testing and demonstrations | Original generated data | Planned |
| Synthea | Synthetic patient records | Apache 2.0 | To verify |
| PubMed Central Open Access | Scientific evidence retrieval | Article-specific licenses | To verify |
| Public clinical terminology resources | Entity extraction and terminology mapping | Resource-specific terms | To verify |

## Data Governance Rules

1. Verify the license before downloading or redistributing any resource.
2. Preserve source attribution.
3. Document restrictions and permitted uses.
4. Never upload real patient records or identifiable health information.
5. Prefer synthetic data for demonstrations and testing.

## Important Note

Availability through a public website does not automatically mean that a dataset can be redistributed.

Each resource must be reviewed individually before inclusion.
