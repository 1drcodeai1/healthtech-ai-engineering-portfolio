# 08 - RAG Evaluation Lab

## Overview

An evaluation framework for measuring the retrieval quality, answer reliability, and citation accuracy of clinical RAG systems.

## Technologies

- Python
- Pandas
- RAGAS
- Scikit-learn
- Matplotlib
- Google Colab

## Main Features

- Retrieval performance evaluation
- Precision@K and Recall@K
- Mean Reciprocal Rank (MRR)
- Citation accuracy checks
- Faithfulness evaluation
- Hallucination analysis
- Evaluation reports and visualizations

## Evaluation Strategy

The project uses a controlled benchmark with synthetic questions and reference answers. It combines automated metrics with human-reviewed examples.

## Safety and Limitations

Evaluation metrics do not guarantee clinical safety or correctness. Results must be interpreted within the limitations of the benchmark.

## Data Privacy

This project uses synthetic questions and publicly available scientific documents.
