# 09 - Clinical AI Audit Trail

## Overview

A traceability and governance system that records AI workflow events, decisions, data provenance, and human review actions.

## Technologies

- Python
- SQLite
- Pydantic
- JSON
- Hashlib
- Google Colab

## Main Features

- Structured event logging
- Workflow traceability
- Source provenance tracking
- Hash-based integrity verification
- Human review records
- Audit reports

## Safety and Limitations

Hash-based integrity checks help detect certain modifications but do not guarantee an immutable or tamper-proof audit system.

## Data Privacy

This project uses synthetic data and contains no real patient information.
