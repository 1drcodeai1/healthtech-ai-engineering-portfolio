# 07 - Clinical Review Agent

## Overview

A human-in-the-loop AI agent that coordinates tools for reviewing synthetic clinical documentation and supporting evidence.

## Technologies

- Python
- LangGraph
- Pydantic
- LangChain
- Google Colab

## Main Features

- Multi-step workflow orchestration
- Clinical information extraction
- Data validation tools
- Evidence retrieval
- Explainable review findings
- Human approval checkpoints

## Safety and Limitations

The agent does not make autonomous clinical decisions, issue diagnoses, or modify patient records. Its outputs require human review.

## Data Privacy

This project uses synthetic clinical data only.
